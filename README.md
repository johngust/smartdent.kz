# ТОО «Смарт Дент» — Стоматологический кабинет доктора Корукпасовой Э.А.

Премиальный высококонверсионный сайт-лендинг для частного стоматологического кабинета в Алматы, полностью подготовленный под Яндекс Директ.

## 🌟 Данные доктора и клиники
- **Главный врач:** Корукпасова Эльмира Абаевна
- **Квалификация:** Стоматолог-терапевт, ортопед, пародонтолог (врач высшей категории, стаж 28 лет).
- **Директор:** ТОО «Смарт Дент»
- **Адрес:** г. Алматы, ул. Айтеке би, 28 (1 этаж), Медеуский район.
- **WhatsApp для записи:** +7 (701) 747-02-41

---

## 🎯 Маркетинговые инструменты под Яндекс Директ:
1. **Спецпредложение (Лид-магнит):**  
   «Комплексная диагностика и консультация врача высшей категории — 0 ₸ (бесплатно) при записи через сайт».
2. **Блок FAQ (Частые вопросы):**  
   Раскрывающийся аккордеон, закрывающий главные страхи (боль, скрытые платежи, стерильность, запись).
3. **Аналитика и цели для автостратегий Директа:**
   - В файле `index.html` (в строке 17) замените `window.METRIKA_COUNTER_ID = 0;` на номер вашего счетчика Яндекс Метрики.
   - Настроены авто-цели `reachGoal`:
     - `whatsapp_click` — любой клик на запись в WhatsApp.
     - `lead_free_diagnostics` — заявка на бесплатную диагностику 0 ₸.
     - `lead_service` — клик по конкретной услуге из прайс-листа.

## 🚀 Запуск и сборка:
- Локальная разработка: `npm run dev` (доступен по http://localhost:5174/)
